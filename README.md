## 📚 Research & Publications

My research interests include IoT-enabled smart agriculture, embedded intelligence, environmental monitoring, machine learning, and intelligent security systems.

Published in the *Journal of Sensors*.

- Combines IoT-based environmental monitoring with an EfficientNet-B0 deep learning classifier.
- Investigates real-time chicken health detection under practical farming conditions.

🔗 [Read the Paper](https://doi.org/10.1155/js/1433795)

**2. Smart IoT Egg Incubator System with Machine Learning for Damaged Egg Detection**

Published in the WorldS4 proceedings by Springer, Cham.

- Integrates environmental control and machine learning for damaged egg detection.

🔗 [Read the Paper](https://link.springer.com/chapter/10.1007/978-3-032-11512-6_20)

**3. Edge-to-Cloud Orchestrated Multi-Sensor IoT Framework for Real-Time WQI Classification and Predictive Assessment via Ensemble ML**

Research focused on water quality monitoring using an ESP32-based sensor system, cloud data integration, and ensemble machine learning.
